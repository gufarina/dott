Bloqueadores pra liberar (por gravidade)

P0
Instalador sem assinatura digital
O Windows mostra “Editor desconhecido / Windows protegeu o seu PC” e a maioria das pessoas leigas desiste de instalar ali. É o maior obstáculo de adoção, não um detalhe.
Conserto: certificado de assinatura de código (OV ~US$200–400/ano ou Azure Trusted Signing ~US$10/mês). Sem isso, todo download assusta.
P0
Não tem atualização automática
Soltou a versão 1.0 e achou um bug? Não há como empurrar a correção — cada pessoa teria que baixar e reinstalar na mão. Na prática, você fica preso à primeira versão.
Conserto: plugin de updater do Tauri + um link de hospedagem (ex: GitHub Releases). Configura uma vez, atualiza pra sempre.
P1
Dado sem backup e sem como exportar
Tudo vive só numa pasta da máquina. Se o PC morre, formata ou desinstala, as notas vão junto. Não há exportar/importar nem cópia de segurança.
Conserto: botão “Exportar tudo” (zip da pasta) + “Importar”. Barato e tira o risco de perda total.
P1
Tarefas guardadas num lugar frágil
Notas e pastas ficam em arquivos seguros, mas as tarefas e o tema ficam na memória interna do navegador embutido (localStorage). Se essa memória é limpa, as tarefas somem — e elas nem entram no backup.
Conserto: mover tarefas pro mesmo sistema de arquivos das notas. Mudança pequena, dado consistente.
P1
Falha ao salvar é silenciosa
Se uma gravação falhar (disco cheio, permissão), o app não avisa nada — a pessoa acha que salvou e pode perder o que escreveu ao fechar.
Conserto: mostrar um aviso quando o salvamento falhar (o app já sabe quando falha, só não fala).
P2
Instalação precisa de internet (contradiz “offline”)
O app roda offline, mas a primeira instalação pode baixar um componente do Windows (WebView2) da internet. Numa máquina sem rede, o instalador pode falhar.
Conserto: uma linha de config pra embutir esse componente no instalador (fica ~100 MB maior, mas instala em qualquer lugar).
P2
Imagens apagadas viram lixo acumulado
Quando você apaga uma nota com imagem, o arquivo da imagem fica pra trás. Com o tempo, a pasta de anexos só cresce, mesmo com poucas notas.
Conserto: faxina automática de anexos sem dono. Não urgente, mas evita inchaço.
P2
Risco raro de duas notas se sobrescreverem
O nome interno de cada nota usa o relógio em milissegundos. Se duas notas nascem no mesmo milissegundo (ex: processar vários cards de uma vez), uma pode escrever por cima da outra.
Conserto: trocar por um id realmente único. Mudança de poucas linhas.
P3
Só Windows · sem controle de versão (git) · só pt-BR
Quem usa Mac fica de fora. O projeto não está num repositório git (sem histórico/rollback). Idioma fixo em português. Nenhum bloqueia o lançamento BR, mas limitam o alcance.
Conserto: decidir depois — começar pelo git local (rede de segurança pro código) é o de melhor custo-benefício.

Contas & armazenamento — o que o usuário precisa saber

Não existem contas

O Dott é por máquina: sem login, sem senha, sem servidor. Bom: zero fricção e privacidade total (ótimo argumento de venda). Limite: nota do notebook não aparece no desktop (sem sync), e não há como recuperar dados se a máquina sumir — nem cobrar/licenciar se um dia virar pago.

Onde os dados moram

Tudo numa pasta do usuário no Windows (%APPDATA%\com.studiofarina.dott): notas .md, inbox, pastas e imagens. Formato aberto — dá pra abrir as notas em qualquer editor. Mas: uma única cópia, num único lugar, sem backup. É o calcanhar de Aquiles hoje.

Tradução prática: a proposta “seus dados são só seus, no seu PC” é forte e verdadeira. Só que “só no seu PC” sem backup é também o maior risco. Resolver exportar/backup antes de liberar transforma o ponto fraco em ponto forte.

Próximos passos — em 3 fases

FAÇA AGORA Liberar pra testadores próximos (amigos/beta fechado)
Objetivo: pôr na mão de 5–15 pessoas de confiança sem risco de perder dados nem sustos no install.
  • Exportar / Importar dados — botão de backup em zip. Tira o risco de perda total.
  • Mover tarefas pro disco — mesmo cofre das notas, entra no backup.
  • Avisar do salvamento que falha — a pessoa nunca perde texto sem saber.
  • Embutir o WebView2 no instalador — instala mesmo offline, sem surpresa.
  • Aviso honesto no download — enquanto não assina, um “clique em Mais informações → Executar” já destrava o beta fechado.
DEPOIS Liberar público (qualquer pessoa baixa)
Objetivo: download sem medo, capacidade de corrigir bugs remotamente.
  • Assinatura digital do instalador — acaba com o “editor desconhecido”.
  • Atualização automática — corrigir bug = todo mundo recebe sozinho.
  • Página de download — um link bonito pra baixar (pode ser na landing do studio).
  • Faxina de anexos órfãos + id único — robustez de longo prazo.
  • Git local do projeto — histórico e rede de segurança pro código.
FUTURO Crescer o alcance
Objetivo: além do BR/Windows, e modelo de negócio se quiser.
  • Sync opcional entre dispositivos — exige contas; decisão de produto (mexe na promessa “100% local”).
  • Versão Mac — Tauri já suporta; falta build + assinatura Apple.
  • Tela de Configurações — trocar atalho, escolher pasta, idioma.
  • Atualizar o brief no studio — hoje descreve um produto menor do que o app virou.
Recomendação da Alia: não tente assinar e fazer auto-update já. Faça a Fase 1 esta semana (é pouca coisa e tira todo o risco de perder dados) e mande pro beta fechado. Use o feedback real pra decidir se vale investir na assinatura paga da Fase 2. Liberar enxuto e seguro > liberar grande e arriscado.
